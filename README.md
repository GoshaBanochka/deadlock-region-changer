# Deadlock Region Changer

Выбор региона матчмейкинга в Deadlock.

## Как это работает

Deadlock подбирает регион по пингу до серверов-ретрансляторов Valve (Steam Datagram Relay).
Программа загружает актуальный список этих серверов из Steam API и блокирует в брандмауэре
Windows все серверы, кроме выбранных. Игра видит только разрешённые серверы и ищет матч там.

Читы и изменения файлов игры не используются, только обычные правила брандмауэра
(все с именем `DeadlockRegionChanger`). Блокируется только исходящий TCP и UDP, поэтому
пинг до заблокированных серверов по-прежнему виден.

- Если у города несколько точек Valve (например, у Франкфурта `fra` и `dfra`, у Стокгольма
  `sto` и `sto2`), они показаны одной строкой и блокируются вместе.
- При каждом запуске программа сверяет IP-адреса серверов с актуальным списком Valve и,
  если они изменились, обновляет правила.
- Пока Deadlock запущен, программа предупреждает, что изменения вступят в силу только
  после перезапуска игры.
- Если брандмауэр Windows выключен, программа предложит его включить: без него
  блокировка не работает.

## Запуск

Скачайте `DeadlockRegionChanger.exe` со страницы релизов (Releases) и запустите. Python
не нужен. Windows запросит права администратора: без них правила брандмауэра не создать.

Настройки и кэш списка серверов хранятся в `%LOCALAPPDATA%\DeadlockRegionChanger`.

Антивирус или SmartScreen может предупредить о неизвестной программе: exe не подписан
цифровой подписью. В SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».

### Из исходников

Нужен Python 3 (без сторонних библиотек). Запустите `run.bat` или:

```bash
py deadlock_region_changer.py
```

### Сборка exe

```bash
build.bat
```

Готовый файл появится в `dist\DeadlockRegionChanger.exe`.

## Как пользоваться

1. Слева выберите пресет («Россия / СНГ», «Европа», «Америка») или включите нужные серверы
   переключателями. Возле каждого сервера показан пинг, слева — ближайший сервер.
2. Нажмите **Применить** внизу окна. Пока изменения не применены, внизу горит
   «Есть неприменённые изменения».
3. Перезапустите Deadlock.

Плашка в правом верхнем углу показывает, действует ли сейчас блокировка.

Чтобы вернуть всё как было, нажмите **Сбросить**. Можно и вручную:

```bash
netsh advfirewall firewall delete rule name=DeadlockRegionChanger
```

## Важно

- Серверов в России у Valve нет. Игроков, которых Valve по IP определяет как российских,
  отправляет во Франкфурт, Стокгольм или Хельсинки (у Хельсинки сейчас нет серверов).
  Пресет «Россия / СНГ» оставляет Франкфурт и Стокгольм. Чтобы не попадать на эти
  маршруты, выключите их все: если заблокировать только один, игру перекинет на другой.
- Если выбрать далёкий регион, пинг в игре будет высоким.
- Если включён VPN в режиме TUN, игра меряет пинг через VPN, и результат может отличаться.
- Если Valve учитывает при подборе страну аккаунта или IP, а не только пинг, одной
  блокировки серверов может не хватить.
